    Un peu de Markdown.
    Beaucoup de possibilités.
    Folio est une liseuse autonome. Ouvrez ce fichier HTML directement, ou déposez-le sur votre site. Aucun serveur de conversion n’est nécessaire.
    01 · Composer votre collection
    Importez plusieurs fichiers ou un dossier complet, ou choisissez « Coller du Markdown ». Vous pouvez aussi coller directement du texte dans la page avec Ctrl / ⌘ V, hors des champs de saisie : un document au nom daté est créé et affiché. Les onglets permettent de passer d’un document à l’autre ; le sommaire suit les titres. La recherche porte sur les noms et le texte. Un fichier réimporté au même chemin met à jour le document. Si ce document était suivi, reliez son original à nouveau : un nom identique ne garantit pas qu’il s’agit du même fichier sur le disque.
    Pour les images, importez aussi les fichiers PNG, JPEG, GIF, WebP ou AVIF. L’import d’un dossier préserve les chemins relatifs. Les liens entre documents importés sont reconnus.
    Chaque document possède une cartouche dans la collection, à gauche. Sélectionnez-le pour retrouver ses commandes Source, Suivi, Imprimer et Télécharger. La corbeille « Supprimer de la collection » retire sa copie de Folio et arrête son suivi ; aucun fichier original n’est effacé.
    02 · Écrire des mathématiques
    Formules en ligne avec $…$ ou \(…\), en bloc avec $$…$$ ou \[…\]. Le moteur KaTeX et ses polices sont intégrés.
    Une énergie $E = mc^2$.

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$
    Les fractions, matrices, sommes et intégrales sont prises en charge. Il s’agit de la syntaxe mathématique de KaTeX, pas d’un compilateur de documents LaTeX complets. Les définitions de macros et les commandes internes ne sont pas prises en charge. Dans du code Markdown, les formules restent du texte. Pour un dollar littéral, écrivez \$.
    03 · Dessiner avec Mermaid
    Entourez votre schéma d’un bloc de code mermaid. Folio le dessine directement dans la page, sans connexion. « Voir le code Mermaid » permet de consulter et copier sa source ; le mode Source conserve le Markdown complet.
    ```mermaid
flowchart TD
    A[Importer] --> B[Lire dans Folio]
    B --> C[Exporter en HTML]
    B --> D[Imprimer]
```
    Les diagrammes gardent un fond clair dans les deux thèmes. Si un schéma contient une erreur, son code et un message restent visibles. Les liens actifs et les ressources distantes des diagrammes sont désactivés. Le moteur accepte jusqu’à 50 diagrammes par document, 16 384 caractères par schéma et 131 072 caractères de diagrammes au total.
    04 · Emporter vos pages
    « Télécharger » propose la page affichée ou toute la collection avec ses onglets. Les HTML contiennent la mise en page, les formules et les diagrammes déjà rendus, et les images locales utilisées. Ils fonctionnent hors connexion. « Imprimer » permet aussi d’enregistrer en PDF depuis le navigateur.
    05 · Retrouver sa collection
    La case « Mémoriser cette collection sur cet appareil », dans la colonne de gauche, enregistre une copie des Markdown et des images locales dans ce navigateur. Elle est décochée par défaut. Après activation, attendez le message « Collection mémorisée » : les documents seront alors restaurés à la prochaine ouverture de cette même page, dans le même profil de navigateur.
    Les ajouts, mises à jour et retraits sont enregistrés pendant la session. Fermer un onglet de document le retire aussi de la collection mémorisée. « Vider la collection » retire tous les documents et toutes les images. Décocher la case supprime la copie enregistrée, tout en gardant les documents affichés jusqu’à la fermeture de la page.
    La mémorisation conserve une copie du contenu. Un simple chemin ne donne pas au navigateur le droit de relire le fichier d’origine. Pour suivre les modifications de cet original, activez aussi le suivi décrit ci-dessous ; sinon, réimportez le Markdown au même chemin pour le mettre à jour.
    Folio ne chiffre pas cette copie. Les pages exécutées sous la même origine (protocole, hôte et port) partagent les droits d’accès au stockage : un dossier différent sur le même site ne protège pas vos documents des autres scripts de ce site. Privilégiez une origine de confiance, idéalement dédiée à Folio.
    Le stockage local dépend des autorisations, des quotas et du navigateur. La navigation privée et l’effacement des données du site peuvent supprimer les copies. L’accès au stockage d’une page ouverte directement depuis le disque peut varier selon le navigateur. Folio affiche les échecs de sauvegarde ou d’effacement ; les exports HTML restent disponibles. Si une autre page modifie la collection, l’enregistrement de cet onglet est suspendu pour éviter d’écraser ses changements.
    06 · Suivre les modifications d’un fichier
    Dans la cartouche du document sélectionné, cliquez sur « Suivi » (les deux flèches), cochez « Recharger automatiquement » puis sélectionnez le Markdown original. Cette autorisation est propre à ce fichier et ne donne qu’un accès en lecture. Le réglage est indépendant pour chaque document. Sur petit écran, ouvrez la colonne des documents avec le bouton à gauche des onglets pour accéder aux commandes.
    Lorsque la page est visible, Folio vérifie le fichier environ toutes les deux secondes et attend une courte stabilité avant de le relire. Le rendu, les formules, les diagrammes et le sommaire sont actualisés ; l’onglet sélectionné, le mode Source et la position de lecture sont conservés autant que la nouvelle longueur du document le permet. Les modifications deviennent visibles une fois enregistrées sur le disque dans votre éditeur. Les images liées restent des copies importées séparément.
    Avec la mémorisation activée, la dernière version lue et le lien autorisé vers l’original sont conservés localement lorsque le navigateur le permet. À la réouverture, la copie s’affiche puis le suivi reprend si l’autorisation reste valable. Sinon, le menu propose « Rétablir l’accès » ou « Choisir l’original ». Aucun dialogue d’autorisation n’est ouvert automatiquement.
    La surveillance s’interrompt quand Folio est fermé et les contrôles sont suspendus lorsque la page est cachée. Un fichier déplacé, supprimé ou remplacé par votre éditeur peut nécessiter « Choisir à nouveau ». Décocher le suivi arrête la lecture automatique et retire la liaison de cette collection ; la dernière version reste affichée. Retirer le document arrête aussi son suivi. Les exports HTML sont des copies figées, sans accès aux originaux.
    Cette fonction nécessite un navigateur proposant le sélecteur de fichiers avec accès autorisé (notamment Chrome ou Edge sur ordinateur), dans un contexte compatible. Un hébergement HTTPS convient ; l’ouverture directe du HTML depuis le disque dépend du navigateur. Si la fonction est indisponible, l’import, les mathématiques, la mémorisation disponible et l’export continuent de fonctionner. Firefox et Safari ne proposent pas actuellement ce sélecteur pour suivre vos fichiers locaux.
    Confidentialité, par construction
    La lecture et la conversion se font dans le navigateur : aucun téléversement, aucune analyse d’audience et aucun cookie. Lorsque la case est décochée et que l’effacement est confirmé, les documents restent uniquement en mémoire pour cette session. Lorsque la case est cochée, une copie est conservée localement dans ce profil de navigateur, sans être envoyée à un serveur.
    Les images distantes sont remplacées par un emplacement descriptif ; aucune ressource externe n’est chargée. Les liens web ne s’ouvrent que si vous cliquez dessus, sans transmettre l’adresse de la page. Le HTML importé est nettoyé avant affichage.
    Avec le code fourni, une page hébergée est téléchargée depuis son hébergeur à l’ouverture et le contenu des fichiers importés ne lui est pas envoyé. Choisissez un hébergement de confiance : une personne capable de modifier l’application servie peut changer ce comportement. Pour une utilisation entièrement hors réseau, ouvrez une copie du fichier HTML enregistrée sur votre ordinateur.
    Repères pratiques
    Ctrl / ⌘ K : rechercher. Flèches gauche/droite dans les onglets : changer de document. Suppr sur un onglet : le fermer. Limites d’import : 5 Mio par Markdown, 15 Mio par image, 80 Mio par collection, 200 documents et 3 000 images. Un glisser-déposer est limité à 3 000 entrées et 64 niveaux de dossiers. Les documents trop complexes et les exports trop volumineux sont refusés avec un message ; exportez alors une collection plus petite. Le rendu accepte jusqu’à 1 000 formules par document et l’export dispose d’un budget estimé de 80 Mio.
    Markdown UTF-8. Les extensions de notes de bas de page ne sont pas interprétées. Les exports individuels conservent les liens vers les autres pages .html : placez-les côte à côte selon l’arborescence d’origine, ou exportez la collection pour garder toute la navigation dans un seul fichier.
